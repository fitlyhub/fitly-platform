# Database Design Guidelines for AI Agents

This document defines the mandatory database schema guidelines that all AI agents must follow when creating new tables in the **Fitly** project.

---

## 1. Table Naming & Module Prefixes

* **Table Prefix**: Every new table must be prefixed with its corresponding module name (e.g., `sys_` for system/IAM, `sales_` for sales module, `inv_` for inventory, etc.).
* **AI Agent Requirement**: AI agents **MUST** explicitly ask the user to clarify the target module prefix before generating any SQL scripts or creating tables. Do not assume or guess the prefix.

---

## 2. Primary Key Rules

* **Primary Key Name**: Must always be formatted as `<table_name>_id`.
  * *Example*: For `sys_user`, the PK is `sys_user_id`. For `sales_order`, the PK is `sales_order_id`.
* **Data Type**: Must always be `uuid`.
* **Generation**: The UUID primary key must be generated by the Application Layer before inserting the record into the database.
  * *Example DDL*: `sys_user_id uuid NOT NULL PRIMARY KEY` (do not use serial/identity auto-incrementing integers).

---

## 3. General Column Guidelines & Data Types

* **Codes, Types, and Groups**: Fields that store codes, statuses, types, or categories must always use `varchar(100)`.
  * *Example*: `code varchar(100)`, `status varchar(100)`, `doc_type varchar(100)`.
* **Names**: Fields storing names or labels must always use `varchar(255)`.
  * *Example*: `name varchar(255)`.
* **Descriptions & Long Text**: Fields storing long content or descriptions must always use `text`.
  * *Example*: `description text`.

---

## 4. Foreign Key Rules

* **Foreign Key Name**: Must match the primary key name of the referenced table (`<target_table_name>_id`).
  * *Example*: A reference to the `sys_org` table must be named `sys_org_id`.
  * *Example DDL*:
    ```sql
    sys_org_id uuid REFERENCES sys_org(sys_org_id)
    ```
* **Cross-Module References (Different Prefixes)**: If the referenced table has a different prefix than the current table (indicating different modules/bounded contexts), **do NOT** define a physical foreign key constraint (`REFERENCES ...`). This keeps modules loosely coupled and makes future migration to microservices easier. Use a simple column of type `uuid` without the physical constraint.
  * *Example*: If a table `sales_order` (prefix `sales_`) references `sys_user` (prefix `sys_`), define the column as `sys_user_id uuid` without adding `REFERENCES sys_user(sys_user_id)`.

---

## 5. Mandatory System Columns (Audit & Metadata)

Every table in the database **MUST** include the following standard system columns for tracking and auditing purposes:

```sql
is_active  boolean   DEFAULT true NOT NULL,
created_at timestamp DEFAULT now() NOT NULL,
updated_at timestamp DEFAULT now() NOT NULL,
created_by uuid,
updated_by uuid
```

---

## 6. Guidelines for Document / Transactional Tables

For tables that represent business transactions or documents (e.g., Sales Orders, Purchase Orders, Invoices, Goods Receipts):

* **Organization Link**: Must include `sys_org_id uuid NOT NULL` (references `sys_org` and cannot be null).
* **Segment Link**: Must include `sys_segment_id uuid` (references `sys_segment`, nullable for now).

---

## 7. Reference DDL Templates

### Template A: General Master / Reference Table
```sql
CREATE TABLE IF NOT EXISTS sys_sample_category
(
    sys_sample_category_id uuid PRIMARY KEY,
    code                   varchar(100) UNIQUE NOT NULL,
    name                   varchar(255) NOT NULL,
    description            text,
    
    -- Mandatory audit columns
    is_active              boolean   DEFAULT true NOT NULL,
    created_at             timestamp DEFAULT now() NOT NULL,
    updated_at             timestamp DEFAULT now() NOT NULL,
    created_by             uuid,
    updated_by             uuid
);
```

### Template B: Document / Transaction Table
```sql
CREATE TABLE IF NOT EXISTS sales_invoice
(
    sales_invoice_id uuid PRIMARY KEY,
    document_no      varchar(100) UNIQUE NOT NULL,
    grand_total      numeric(18,4) DEFAULT 0 NOT NULL,
    
    -- Mandatory document columns
    sys_org_id       uuid NOT NULL REFERENCES sys_org(sys_org_id),
    sys_segment_id   uuid REFERENCES sys_segment(sys_segment_id),
    
    -- Mandatory audit columns
    is_active        boolean   DEFAULT true NOT NULL,
    created_at       timestamp DEFAULT now() NOT NULL,
    updated_at       timestamp DEFAULT now() NOT NULL,
    created_by       uuid,
    updated_by       uuid
);
```
